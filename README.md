# TaskFlow Lite

An enterprise-style simple task management system.
Docs: Confluence space - TaskFlow Lite Documentation (TL-DOC)

## Quick start (local)
1. Start Postgres + backend: `docker-compose up --build`
2. In backend: `npm install` then `npx prisma migrate dev` then `npm run dev`
3. Open frontend (react) with `npm run dev` in frontend folder
